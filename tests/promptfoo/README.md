## 运行（约 5 分钟）

```bash
cd E:\jieqi-shidan\tests\promptfoo

# 1. 配置密钥（只放在当前终端环境变量里，不要写进任何文件）
set DEEPSEEK_API_KEY=sk-你的密钥        # CMD
# 或 PowerShell：  $env:DEEPSEEK_API_KEY="sk-你的密钥"

# 2. 跑测试（首次会自动安装 promptfoo）
npx promptfoo@latest run

# 3. 打开网页报告逐条核对
npx promptfoo@latest view
```
