# 圆窗首页与水墨交互

用户明确要求：按截图恢复圆形山景、左右竖题、大号节气名称和四格节气信息；首页与全部24节气详情采用水墨交互。

设计：保留本地山景照片、宣纸底色、朱砂题签与原有阅读结构。首屏去掉立冬专用3D庭院分支，恢复统一月洞门。使用本地Canvas2D绘制鼠标带起的墨丝、细墨点和扩散墨晕；加入低对比远山静态底纹。无需额外生图或服务器。

实现：独立INK_WASH模块，根据页面data标记挂载；路由、收藏重绘和推荐换批时释放旧实例。鼠标移动触发细墨飞散，触屏轻触留白触发一次扩散，按钮和文字重点区域保护。输入停止后动画自然结束并停止帧循环；页面隐藏时取消帧；低动态偏好禁用粒子；提供暂停开关并跨路由保留暂停选择。

验证：测试粒子触发、低动态、隐藏、重挂载、销毁后的监听和帧；浏览器检查首页圆窗、全部24个详情、收藏重绘、跨路由清理、6种宽度及真实Canvas像素变化。部署后再检查线上文件与交互。

原React Three Fiber源码与资源保留以便后续复用，本次首页不再加载庭院。
