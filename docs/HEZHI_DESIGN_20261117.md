# 禾知点阵问答页

采用用户已选择的禾知方向：米白谷粒身体、墨绿稻叶、安静的双眼，局部青绿/浅金点阵。纸色和朱砂沿用现有品牌。

技术：在原静态H5上增加独立React Three Fiber岛，点云使用本地程序化几何和自定义点着色器，不用远程模型、图片或额外API。仅问答页延迟加载。WebGL不可用或加载失败时保留静态SVG形象；低动态或暂停时按需绘制，隐藏/离屏/离页停止。现有React/Three/Fiber版本与许可收集流程复用。

页面：紧凑视觉中心、标题“这一餐，顺着节气吃”、当前节气标签、2×2快捷入口。开始提问后形象缩为小头像；等待、请求中、流式回答、完成、失败必须由真实请求生命周期驱动。服务状态依据AI.status，不伪造在线状态。

边界：本次实现界面和交互，不新增账号、语音或团队API服务，不把演示请求写成真实服务接通。保留输入、停止、重试、收藏、复制、搜索和设置。

验收：真实WebGL点云、悬停/轻触反应、暂停与低动态、路由卸载、无WebGL降级、多宽度布局。请求状态用无外部调用的受控回调验证；公开站的未配置行为单独检查。
