# 禾知点阵验收

2026-11-17

已实现：

- 谷粒身体、稻叶、双眼和浅金轨迹，6220个本地点构成三维形象；仅问答页加载WebGL构建资源。
- 悬停视角轻转和聚散，触屏轻触短暂散开后回拢。
- 问答页新标题、节气标签、2×2入口；进入对话后头像缩小，流式消息不重建Canvas。
- 真实请求回调驱动等待、请求中、回答中、完成、失败状态。
- 请求离页后取消并忽略过期回调，移除旧事件委托，防止反复进入后重复执行。
- 暂停、低动态、后台与离屏暂停；加载失败/禁用WebGL时保留静态SVG形象和原有问答入口。

已验证：

- npm test：28项通过。新增测试覆盖懒加载未结束就离页、待加载状态保留、低动态/可见性和事件释放。
- Edge实际WebGL、请求中/流式/完成/失败状态、停止和重试均通过受控回调验证。
- 请求回调为本地受控测试，没有调用外部收费AI接口，不代表已确认真实服务可回答。
- 流式更新时同一Canvas保留；暂停前后截图像素一致；过期回调不污染离页后的消息。
- 320/375/393/430/768/1440六种宽度无横向溢出。
- 阻断构建文件和禁用WebGL两种降级均保留静态形象及快捷入口。
- 浏览器触屏模拟验证轻触聚散在抬指后短暂保留并回拢；反复进出页面后一次收藏只执行一次。

待核验：实体低端手机帧率和温升、更多浏览器/系统组合、当前访问者配置下的实际AI请求。语音、账号服务和额外AI接口未新增。
