# DESIGN.md · 节气食单 古中式视觉规范 v2

> 依据 chinese-web-design Skill 流程产出；强度档：**丰富**（雅致↔浓烈之间，重氛围不失可读）；交互档：**L2**（首页 Hero 局部 L3）。
> 冲突裁决：主色「节气青 #3F7D5A」为项目需求定稿强制保留，其余颜色全部取自《中华传统色》742 色清单并注释色名。

## 1. 设计哲学与氛围

**「一窗四季，纸上时令」**——以月洞门为一扇看季节的窗，宣纸为底，水墨为动，印章为记。华丽来自层次与细节（描金线、回纹、竖排款识），不来自高饱和堆叠。内容层级永远高于装饰（项目需求红线）。

季节动态主题（随当前/浏览节气切换，0.8s 过渡）：
春 #8FB56A 官绿系 ／ 夏 #2E6B4F 苍绿系 ／ 秋 #C08A2E 秋香系 ／ 冬 #3A4459 黛蓝系（每节气另有专属色 c，来自内容数据）。

对比度：墨色/汉白玉 ≈ 13:1 ✓；ink2/paper ≈ 6.5:1 ✓；ink3 仅用于辅助小字；朱砂只做小面积记号，不做正文色。

## 3. 字体

- 标题/款识（serif 楷体系）：`"Kaiti SC","STKaiti","KaiTi","DFKai-SB","Noto Serif SC","SimSun",serif`——离线本地方案（项目要求静态可离线，不引 Google Fonts；气质对标 LXGW WenKai）。
- 正文（sans）：`"PingFang SC","HarmonyOS Sans SC","Microsoft YaHei",sans-serif`。
- 大字距是中式气质的关键：标题 .06–.34em，款识 .2em+。
- 诗词块行高 2.0、字距 .14em（赫蹏 Heti 精简内联实现：标点悬挂不做，段落节奏靠行高与字距）。

## 4. 组件手法（东方语汇落点）

- **印章**：logo 印（節氣）、「今日」封缄、打卡盖章动画（scale+rotate 落印）。
- **竖排款识**：首页两侧「天人合一／时序流转」（窄屏隐藏）。
- **描金细线**：1px 鎏金/秋香分隔与卡片 hover 描边。
- **回纹/云纹**：区块标题两侧简化回纹（CSS border 造角，不用图片）。
- **汉字章节号**：百科分区「春/夏/秋/冬」用汉字大号+季色。
- **月洞门**：首页 Hero 圆窗 SVG 山水（每节气专属意象），百科中心圆盘呼应。

## 5. 动效（L2）

路由入场 fade+8px 上移（0.36s, cubic-bezier(.22,.61,.36,1)）；滚动 reveal（IntersectionObserver, 阶梯 60ms）；Hero 水墨粒子 canvas（移动端 ≤16 粒，随 --c2 季色，visibility 暂停）；换一换卡片轻颤入；打卡=盖章。全部尊重 prefers-reduced-motion（粒子关闭、动画归零）。悬停态仅 hover 设备生效（hover:none 断点）。

## 6. 避廉价红线（自 Skill，逐条自检）

✗ 纯黑纯白（纸色+墨色代替）✗ 大红配明黄 ✗ 渐变金字描边字 ✗ 满屏龙凤堆砌 ✗ CSS 渐变画实物 ✗ 动效喧宾夺主。
✓ 墨配纸 ✓ 一主色（节气青）+ 一点印章红 ✓ 留白成块 ✓ 真内容驱动装饰。

## 7. 响应式

基准 375–430px；无横向滚动（验收 19）；触控 ≥44px（验收红线）；375px 下竖排款识隐藏、节气盘缩至 300px；安全区 env(safe-area-inset-*)。

## 8. 状态与诚实性（不可破坏）

五态齐全（加载/空/失败×2/正常）；「演示数据 · 待核验」角标保留；未接通 AI 不伪造；印章红只盖在真实完成态上（不假成功）。
