# 圆窗与水墨改版验收

2026-11-17

已实现：

- 首页恢复圆形山景、两侧竖排题字、大号节气名称与节奏信息条；立冬不再使用专用3D首屏。
- 首页与24节气详情使用同一套宣纸远山、水墨点、墨丝和扩散墨晕。
- 鼠标移动触发飞墨，触屏轻触留白触发短暂扩散；暂停选择跨路由保留。
- 保护标题、信息条与操作区；输入结束后停止帧，隐藏、低动态和离开页面时取消绘制。
- 原三维源码和已制作的功能图标、PPT保留。

已验证：

- npm test：26项通过；新增水墨测试覆盖输入、空闲停止、分辨率上限、暂停、隐藏、低动态、重复挂载和监听释放。
- Edge浏览器检查全部24节气详情均只有一个水墨Canvas；收藏重绘后旧实例被清理。
- 真实Canvas像素读取确认鼠标输入后产生墨色，暂停后像素清空。
- 首页、详情、我的在320/375/393/430/768/1440宽度均无横向溢出；我的页面没有水墨实例残留。
- 浏览器触屏模拟轻触触发扩散；首页不请求React Three Fiber庭院构建资源。
- 截图已检查首页与大寒详情的稳定画面。

边界：触屏为浏览器模拟，未进行实体手机性能测试。圆窗仍使用原本地山景照片的降色处理，远山与交互由SVG/Canvas绘制，不是新生成的24张水墨画。
