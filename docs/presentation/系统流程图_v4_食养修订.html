四 · 相对 v3 流程图的主要修改对照（答辩讲解用）
#v3 设计稿实施版 v4（修改后）
1NFC 贴卡 / 扫码独立入口，参数规则未统一统一 ?t=节气拼音 参数协议，NFC / 二维码 / 分享链接共用；卡片实机验证待记录
2节气定位规则笼统（"先进接近此时时间"）明确三级优先级 + 按年交节表（按年核验 / 范围外提示未收录）
3账号能力属【规划】，登录读取账号资料用户决策提前纳入第一版：本机账号（无后端条件下的诚实实现，界面标注能力边界）
4AI 有"检索依据"环节（类似 RAG）落地为 DeepSeek 流式直答 + 生成后过敏校验 + 医疗边界声明；未接通 / 失败全部如实展示
5换菜仅重新过滤排序，状态未定义换一换存菜品 ID 列表，池变化自动重算；每道菜附推荐理由
6食单假定"已审核菜谱"建立「演示数据 · 待核验」标注体系：出处随条目标注、核验状态逐条更新（诗词/古籍同规则）
7收藏加回"复检最新口径"仅为设想规则：加回时按最新忌口复检，冲突拒绝并说明原因
8未定义部署形态纯静态 H5 + Hash 路由（发布状态以本轮记录为准）；数据全在本机 localStorage；AI 服务与代理状态按实测记录
