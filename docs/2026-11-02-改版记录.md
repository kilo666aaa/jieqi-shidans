# 节气食单 · 教师反馈改版记录

本轮依据用户于 2026-11-02 确认的设计实施。原始历史 ZIP、Word 需求和流程图未覆盖。

## 已实现

- 13 屏固定 iPhone 16 393×852 逻辑画布黑白原型，长内容在屏幕内部滚动。
- v2 / v4 流程图修订副本；v2 的 170 个图形标签（含主要连接路径）及根 SVG 几何与原稿相同，v4 保持原布局样式与四列顺序。
- 原生 Canvas 透视粒子登录/注册界面；保留本机账号、访客与错误状态，无新增后端。
- 暖纸、墨绿、铜金视觉；正文 600、标题 800；统一圆角和至少 44px 操作控件。
- 24 个独立原创圆徽 SVG，与科普图解分别设计；可复用文件位于 `assets/seasonal/icons/`。
- 24 个独立 8 秒等距 SVG 图解，播放、暂停、重播、拖动进度、低动态和离屏暂停。
- 百科增加天文黄经、气候地域、常见误解、传统食养、现代饮食与起居参考、来源和审核范围。
- 修正“东风解冻”释义、雷声唤醒昆虫和“鹰化为鸠”等科学表述。旧诗词、古籍和地域食俗仍保留待核验状态。
- AI 上下文加入传统食养、现代建议、审核状态、来源标题和适用范围，增加食养快捷提问。
- 首页、菜谱和收藏接入本地实拍图片；区分“菜品实拍”和“食材参考 · 非成品”，详情附署名与许可。
- 静态资源统一版本号，防止沿用改版前缓存。

## 验证证据

- 登录粒子测试先缺模块失败，再通过；覆盖低动态和释放全局监听/动画。
- 百科测试逐项检查 24 黄经、实际 SVG 图形唯一性、24 动画不同状态、旧数据纠错及播放/可见性/低动态/卸载。
- 推荐回归按 9 类已标注过敏原遍历 24 节气，每项轮换 6 次，未将命中标注的菜品加入推荐。
- AI 上下文测试先观察来源范围断言失败，补齐 review/title/scope 后通过。
- 浏览器实测 375、393、430 和 1440 视口，五类页面共 20 组，无横向溢出；抽取的正文、控件与标题计算字重为 600 / 800。
- 浏览器逐页打开 24 节气：各有一个独立图解和来源，无横向溢出。
- 浏览器实测本机注册、错误密码拒绝、正确登录；使用虚构本地验收账号，未调用短信或第三方账号服务。
- 浏览器实测换一换、收藏与刷新后留存、打卡、坚果过敏过滤和加回冲突拒绝。
- `?t=bailu` 实际进入白露食单，进入详情并刷新仍为白露；未进行实体 NFC 卡碰一碰测试。
- 低动态模拟下图解显示静态状态；霜降图解播放/暂停有效。
- 独立审阅发现并修复：收藏食材标签被 CSS 隐藏、AI 来源范围丢失、展示材料候选数与推荐数混淆；定向复核关闭这三项。
- 开发中确认浏览器会沿用同版本 JS 缓存；测试时禁用缓存验证真实改动，交付前统一升资源版本。

## 证据边界

- 当前是静态 H5 与本机演示账号，不是跨设备账号系统，也不是已发布的小程序或原生 APP。
- AI 实际外部服务调用未重新配置或验收；未配置时页面如实显示未接通。没有写入或读取用户 API 密钥。
- 24 个黄经对照天文台；新增内容不是医学专家或文化专家逐项审核稿。旧菜谱与诗词仍需小组人工审核，2027–2029 交节表仍待复核。
- 实拍中的食材参考不是对应菜品成品，不计作成品照补齐；照片作者不背书本站。
- 尚未向 GitHub 推送，本记录不代表线上已更新。
